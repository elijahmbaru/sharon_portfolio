# Sharon Wangari — UX and Researcher Portfolio

Personal portfolio website for Sharon Wangari, a product designer and UX researcher working across fintech, logistics, and FMCG.

## Case Studies

- **Agri-Finance** — Financial tools for smallholder farmers
- **Chargebacks (Dart)** — Chargeback dispute management for merchants
- **DevRel Research** — Developer relations and community research
- **MHM Kenya** — Menstrual health management in Kenya
- **PayPal Checkout** — Checkout flow UX improvements
- **Paystack Settlements** — Settlements experience for businesses
- **Sendy Supply** — Supply chain and logistics product design
- **Watchtower Navigation** — Navigation design for a monitoring platform
- **Zambia VSLA** — Village savings and loan associations in Zambia

## Stack

Static HTML/CSS site with no build step required. Open any `.html` file directly in a browser or serve with any static file server.
